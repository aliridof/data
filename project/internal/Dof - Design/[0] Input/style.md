Create a professional enterprise-grade web application interface focused on operational efficiency, information density, and functional clarity.

The design should prioritize usability, monitoring, management, and decision-making workflows rather than marketing aesthetics.

VISUAL STYLE

The interface should feel like:

- mission control software
- enterprise operations platforms
- monitoring systems
- technical management tools
- industrial software
- professional administration systems
- engineering-grade applications

The visual language should communicate:

- reliability
- precision
- clarity
- professionalism
- operational awareness

Avoid:

- startup SaaS trends
- excessive gradients
- glassmorphism
- neumorphism
- oversized cards
- decorative illustrations
- playful visual elements
- social media styling

DESIGN PRINCIPLES

Functional First

Every UI element must have a clear purpose.

Information First

Users should understand the system status within seconds.

Consistency First

All modules should follow the same visual structure.

Efficiency First

Reduce clicks, scrolling, and cognitive load.
